# Математическая модель

Реализация: `backend/domain/decision/` (модули `models`, `topsis`, `pareto`,
`sensitivity`, `analysis`). Номера формул ниже совпадают с комментариями в коде.

## 1. Задача выбора

Дано множество альтернатив (обученных моделей) $M = \{M_1, \dots, M_m\}$, полученных
**на одном датасете, одной задаче и одном протоколе оценки** (одни фолды, один seed).
Модели из разных задач в одну матрицу не объединяются: импорт ModelArena берёт один
прогон, а CSV/JSON-матрица описывает один контекст.

Критерии $C = \{c_1, \dots, c_n\}$, у каждого:

* направление $d_j \in \{\max, \min\}$;
* вес $\tilde w_j \ge 0$ в произвольном масштабе;
* роль: оцениваемый ($\tilde w_j > 0$) или только для ограничений ($\tilde w_j = 0$).

Матрица решений $X = (x_{ij})$, где $x_{ij} \in \mathbb{R} \cup \{\varnothing\}$;
$\varnothing$ — «не измерено». **$\varnothing$ не заменяется нулём**: альтернатива
с $\varnothing$ по оцениваемому критерию исключается из сравнения со статусом
`incomplete`. Каждому значению может быть сопоставлена стандартная неопределённость
$\sigma_{ij} \ge 0$ (для метрик качества — стандартное отклонение по фолдам).

Эффективные веса: $w_j = \tilde w_j / \sum_{k:\tilde w_k>0} \tilde w_k$, $\sum w_j = 1$.
Корректность: все $\tilde w_j$ конечны и неотрицательны, хотя бы один положителен.

Жёсткие ограничения $G = \{(j, \circ, b)\}$, $\circ \in \{\le, \ge\}$.
Для альтернативы $i$ ограничение имеет три состояния: выполнено, нарушено,
**не проверено** ($x_{ij} = \varnothing$). Не проверенное ограничение не считается
выполненным.

## 2. Классический TOPSIS (режим B)

2.1. Нормализация (векторная):
$$r_{ij} = \frac{x_{ij}}{\sqrt{\sum_{k} x_{kj}^2}}$$
или min-max: $r_{ij} = (x_{ij} - \min_k x_{kj}) / (\max_k x_{kj} - \min_k x_{kj})$.

2.2. Взвешивание: $v_{ij} = w_j r_{ij}$.

2.3. Идеал и антиидеал:
$A^+_j = \max_i v_{ij}$, $A^-_j = \min_i v_{ij}$ при $d_j = \max$; наоборот при $d_j=\min$.

2.4. Расстояния: $D^+_i = \lVert v_i - A^+ \rVert_2$, $D^-_i = \lVert v_i - A^- \rVert_2$.

2.5. Близость: $C^*_i = D^-_i / (D^+_i + D^-_i) \in [0,1]$; ранжирование по убыванию.
Равные (с точностью $10^{-12}$) близости делят место (ранги «1, 1, 3»).

Краевые случаи:

* столбец с нулевой нормой или нулевым размахом не различает альтернативы:
  его вклад нулевой, критерий помечается как вырожденный;
* $D^+_i + D^-_i = 0$ означает, что идеал совпал с антиидеалом по всем критериям
  (все альтернативы одинаковы): $C^*_i = 0.5$ для всех.

### 2.6. Проверочный пример (вручную, тест `test_topsis_matches_hand_computed_example`)

$X = \begin{pmatrix}0.9 & 10\\ 0.8 & 5\\ 0.7 & 20\end{pmatrix}$, $d = (\max, \min)$, $w = (0.6, 0.4)$.

* нормы столбцов: $\sqrt{0.81+0.64+0.49} = 1.392839$, $\sqrt{100+25+400} = 22.912878$;
* $r_1 = (0.646162,\ 0.436436)$, $r_2 = (0.574367,\ 0.218218)$, $r_3 = (0.502571,\ 0.872872)$;
* $v_1 = (0.387697,\ 0.174574)$, $v_2 = (0.344620,\ 0.087287)$, $v_3 = (0.301542,\ 0.349149)$;
* $A^+ = (0.387697,\ 0.087287)$, $A^- = (0.301542,\ 0.349149)$;
* $D^+ = (0.087287,\ 0.043077,\ 0.275670)$, $D^- = (0.194676,\ 0.265381,\ 0)$;
* $C^* = (0.690431,\ 0.860346,\ 0)$ → ранги $(2, 1, 3)$.

## 3. Режим A — по основной метрике

Победитель $\arg\max$ (или $\arg\min$) основной метрики качества $p$ среди альтернатив
с измеренным $x_{ip}$. Ограничения не применяются; если победитель их нарушает, это
сообщается. Альтернатива $k$ называется **статистически неотличимой** от победителя $i$,
если $|x_{ip} - x_{kp}| \le \max(\sigma_{ip}, \sigma_{kp})$ — то же правило, что
в ModelArena. Это эвристика, а не статистический тест.

## 4. Режим C — ограничения, Парето, TOPSIS, устойчивость (CP-TOPSIS-R)

4.1. Допустимое множество:
$F = \{ i : x_{ij} \ne \varnothing\ \forall j: w_j>0;\ \text{все ограничения выполнены} \}$.
Недопустимые альтернативы **не скрываются**: у каждой статус и причина.

4.2. Доминирование: $a \succ b \iff \forall j: a_j \succeq_j b_j \wedge \exists j: a_j \succ_j b_j$
(сравнение по оцениваемым критериям с учётом направления). Парето-множество
$P = \{ i \in F : \nexists k \in F,\ k \succ i\}$.

4.3. TOPSIS (разд. 2) на $P$ — итоговое ранжирование и рекомендация.

**Утверждение 1 (инвариантность к доминируемым альтернативам).** Пусть $z \notin F$
или $z$ доминируется некоторой $k \in F$. Тогда ранжирование режима C на $F \cup \{z\}$
совпадает с ранжированием на $F$.

*Доказательство.* Если $z$ недопустима, она не входит в $F$. Иначе $z$ доминируется,
а значит $z \notin P$. Добавление $z$ не исключает из $P$ ни одну альтернативу: если бы
$z \succ y$ для $y \in P$, то по транзитивности $k \succ y$ — противоречие с $y \in P$.
Следовательно, $P$ не меняется, и все величины формул 2.1–2.5 (нормы, идеалы, расстояния)
вычисляются на том же множестве. ∎

Утверждение не распространяется на добавление **недоминируемой** альтернативы:
оно меняет нормы и идеалы, и rank reversal возможен (ограничение метода).

## 5. Анализ устойчивости

5.1. **Интервалы весов (one-at-a-time).** Для оцениваемого критерия $j$ при $t \in [0,1]$:
$w_j(t) = t$, $w_k(t) = w_k (1-t)/(1-w_j)$ для $k \ne j$. Победитель вычисляется на сетке
с шагом $h$ (по умолчанию 0.01) плюс точка $t = w_j$. Интервал устойчивости —
максимальный отрезок сетки вокруг $w_j$ с тем же победителем. Точность границ — $\pm h$.

5.2. **Локальная доля сценариев весов.** $w^{(s)} \sim \mathrm{Dir}(\kappa w)$, $s=1..S$;
$\mathbb{E}[w^{(s)}] = w$, разброс уменьшается с ростом $\kappa$ (по умолчанию $\kappa=50$).
$\mathrm{share}_i = \frac1S \sum_s [i \text{ первая при } w^{(s)}]$ (ничья делит сценарий).

5.3. **Глобальная доля** (идея SMAA): $w^{(s)} \sim \mathrm{Dir}(1,\dots,1)$ —
равномерно по симплексу.

5.4. **Устойчивость к шуму измерений.** Веса фиксированы,
$\tilde x_{ij}^{(s)} = x_{ij} + \varepsilon$, $\varepsilon \sim \mathcal N(0, \sigma_{ij}^2)$;
неизвестная $\sigma_{ij}$ принимается за 0, о чём выдаётся предупреждение
(оптимистичное допущение).

5.5. **Вердикт.** $q = \min(\mathrm{share}^{local}_{win}, \mathrm{share}^{noise}_{win})$;
«устойчивая» при $q \ge \theta$, «условная» при $\theta/2 \le q < \theta$, иначе
«неустойчивая» ($\theta = 0.6$ по умолчанию). Если $|P| = 1$ — устойчивая по построению.

**Интерпретация.** Доля сценариев — мера чувствительности выбора к весам и шуму,
**не вероятность** того, что модель «на самом деле лучше». TOPSIS не является
статистическим тестом и не доказывает значимость различий.

Все случайные величины порождаются `random.Random(seed)` (seed, seed+1, seed+2 для трёх
анализов): результат побитово воспроизводим; вход фиксируется SHA-256 отпечатком.

## 6. Диагностика фактического влияния критерия

$$\mathrm{infl}_j = \frac{\max_i v_{ij} - \min_i v_{ij}}{\sum_k (\max_i v_{ik} - \min_i v_{ik})}$$

Расстояние между любыми двумя альтернативами по критерию $j$ не превосходит размаха
$\max_i v_{ij} - \min_i v_{ij} = w_j (\max_i r_{ij} - \min_i r_{ij})$. При векторной
нормализации $\max r_j - \min r_j = (\max x_j - \min x_j)/\lVert x_j \rVert_2$, то есть
пропорционален относительному размаху критерия. Для метрик качества в узком диапазоне
(ROC-AUC 0.95–0.99) он мал, и $\mathrm{infl}_j \ll w_j$. Предупреждение выдаётся при
$w_j \ge 0.15$ и $\mathrm{infl}_j < w_j/3$. Показатель описательный и в формулу выбора
не входит.

## 7. Прочие проверки

* несколько метрик одной группы `quality` с ненулевым весом — предупреждение о двойном учёте;
* $|r_{\text{Pearson}}| \ge 0.9$ между оцениваемыми критериями (при $m \ge 4$) —
  предупреждение о коррелированных критериях;
* min-max нормализация — предупреждение о растяжении малых различий.

## 8. Сложность

TOPSIS — $O(mn)$. Анализ устойчивости — $O(S\,mn)$ для каждой из трёх выборок
и $O(n \cdot (1/h) \cdot mn)$ для интервалов; Парето — $O(m^2 n)$. Измерено: 100
альтернатив, 3 критерия, $S=2000$ — 0.3 с (см. RESULTS.md).

## 9. Режим D — TOPSIS на фиксированных шкалах (гипотеза H4)

Реализация: `backend/domain/decision/scales.py`, `analysis._fixed_mode`. Режим добавлен
**рядом** с B и C, они не изменены.

9.1. **Шкала** критерия $j$ — пара опорных значений $(x^0_j, x^1_j)$ и тип: значение
$x^0_j$ даёт полезность 0, $x^1_j$ — полезность 1. Шкала задаётся **до сравнения** и не
зависит от состава набора альтернатив.

* линейная: $u_{ij} = \mathrm{clip}_{[0,1]}\big((x_{ij} - x^0_j)/(x^1_j - x^0_j)\big)$;
* логарифмическая (ресурсы, $x>0$): $u_{ij} = \mathrm{clip}_{[0,1]}\big((\ln x_{ij} - \ln x^0_j)/(\ln x^1_j - \ln x^0_j)\big)$.

Логарифм выбран для времени, размера и памяти потому, что для ресурса значима кратность:
ускорение с 2 до 1 мс и со 200 до 100 мс одинаково полезны. Направление задаётся порядком
опор: для max-критерия $x^1_j > x^0_j$, для min-критерия $x^1_j < x^0_j$ (иначе — ошибка входа).

9.2. **Выбор шкал** (источник показывается пользователю):

| Источник | Критерий | Шкала | Обоснование |
|---|---|---|---|
| естественная | ROC-AUC | линейная, $0.5 \to 1$ | 0.5 — уровень случайного классификатора; ниже 0.5 модель хуже случайной, полезность 0 |
| естественная | R² | линейная, $0 \to 1$ | 0 — предсказание средним; отрицательный R² обрезается до 0 |
| естественная | доли (accuracy, F1, …) | линейная, $0 \to 1$ | границы доли; уровень случайного угадывания не учтён (ограничение) |
| бюджет | ресурс с ограничением $\le B$ | логарифмическая, $B \to B/100$ | $B$ — худшее допустимое значение по условию пользователя; $B/100$ — «лучше уже не нужно», параметр |
| пользователь | любой | заданная | — |
| по данным | остальные | min/max наблюдаемых | запасной вариант; инвариантность для критерия теряется, выдаётся предупреждение |

Множитель 100 — условный параметр, а не вывод из данных. Его влияние измерено
(RESULTS.md, разд. 9).

9.3. **Близость.** $v_{ij} = w_j u_{ij}$; идеал и антиидеал фиксированы: $A^+ = w$, $A^- = 0$;
$$D^+_i = \sqrt{\textstyle\sum_j w_j^2 (1 - u_{ij})^2},\quad D^-_i = \sqrt{\textstyle\sum_j w_j^2 u_{ij}^2},\quad C^D_i = \frac{D^-_i}{D^+_i + D^-_i}.$$

Ограничения применяются так же, как в режиме C (разд. 4.1). Парето-фильтр не нужен
(утверждение 3).

**Утверждение 2 (независимость от посторонних альтернатив).** Если все шкалы
заданы не по данным, то $C^D_i$ зависит только от $x_i$, $w$ и шкал. Следовательно,
добавление или удаление любой другой альтернативы (доминируемой или нет) не меняет
ни близость, ни взаимный порядок остальных.

*Доказательство.* $u_{ij}$ вычисляется по $x_{ij}$ и фиксированным $(x^0_j, x^1_j)$;
$A^+, A^-$ не зависят от матрицы; $D^\pm_i$ и $C^D_i$ — функции строки $i$. ∎

**Утверждение 3 (монотонность по доминированию).** Если $a \succ b$, то $C^D_a \ge C^D_b$.

*Доказательство.* Полезность — неубывающая функция значения в предпочтительном
направлении (композиция монотонного преобразования и обрезки), значит $u_{aj} \ge u_{bj}$
для всех $j$. Тогда $D^+_a \le D^+_b$ и $D^-_a \ge D^-_b$. Функция $D^-/(D^+ + D^-)$
не убывает по $D^-$ и не возрастает по $D^+$, откуда $C^D_a \ge C^D_b$. Равенство
возможно, если различие попадает в обрезанную часть шкалы. ∎

9.4. **Что режим D не гарантирует.** Фактическое влияние критерия (разд. 6, в пространстве
полезностей) по-прежнему зависит от разброса альтернатив **внутри** шкалы: если все модели
имеют ROC-AUC 0.98–0.99, их полезности 0.96–0.98 почти не различаются, и вес качества снова
мало влияет на выбор. Режим D делает это влияние **интерпретируемым** («разница 0.01 ROC-AUC
— это 2% осмысленного диапазона»), но не равным весу. Вес в TOPSIS — не гарантированная
доля влияния ни в одной из нормализаций.
