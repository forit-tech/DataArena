# Экспериментальный протокол

Метрики и критерии оценки объявлены до анализа результатов. Синтетические сценарии
помечены как синтетические и не выдаются за результаты моделей.

## 1. Данные

Встроенные в scikit-learn открытые датасеты (не скачиваются, происхождение указано
в документации scikit-learn):

| Датасет | Задача | Строк | Признаков | Основная метрика |
|---|---|---|---|---|
| breast_cancer (UCI WDBC) | бинарная | 569 | 30 | ROC-AUC |
| digits_binary (UCI optical digits, цель «цифра ≥ 5» — производная задача) | бинарная | 1797 | 64 | ROC-AUC |
| wine (UCI Wine) | 3 класса | 178 | 13 | ROC-AUC (one-vs-rest) |
| diabetes (Efron et al., 2004) | регрессия | 442 | 10 | R² |

Это **малые учебные датасеты** — ограничение внешней валидности (см. разд. 6).

## 2. Модели и измерения (стенд `scripts/research/measure_models.py`)

Классификация: логистическая регрессия, дерево решений, случайный лес (300), градиентный
бустинг, kNN (7), SVM (RBF), наивный Байес, MLP (64). Регрессия: ридж, дерево, случайный
лес (300), градиентный бустинг, kNN, SVR, MLP.

* протокол: 5 фолдов (StratifiedKFold для классификации, KFold для регрессии), shuffle,
  seed 42; препроцессинг внутри Pipeline — масштаб обучается только на train-фолде;
* качество — среднее и std по фолдам;
* время обучения — среднее по фолдам; инференс — медиана 5 повторов на test-фолде
  в пересчёте на 1000 строк, затем среднее по фолдам;
* размер — pickle модели, обученной на всём датасете;
* окружение (Python, scikit-learn, NumPy, ОС, процессор) записывается в каждый файл.

## 3. Сценарии сравнения (стенд `scripts/research/decision_experiment.py`)

Критерии: основная метрика качества, инференс, размер (одна метрика качества — без
двойного учёта). Для каждого датасета:

* **4 профиля весов** (те же, что в интерфейсе): balanced 4:2:2, quality 8:0.5:0.5,
  edge 3:3:3, latency 3:6:1 (качество : время : размер);
* **5 наборов ограничений** на медианах наблюдаемых значений: нет; инференс ≤ медианы;
  размер ≤ медианы; качество ≥ медианы; качество ≥ медианы и инференс ≤ медианы.

Итого 4 × 4 × 5 = 80 сценариев, из них 64 с ограничениями. Seed 20261109, S = 1000.

## 4. Метрики (объявлены заранее)

| Обозначение | Метрика | Гипотеза |
|---|---|---|
| M1 | доля сценариев с ограничениями, где победитель режима нарушает ограничение | H3 |
| M2 | доля «приманок» (доминируемых альтернатив, 20 на сценарий: хуже базовой по качеству на 0–5% и по ресурсам в 1–3 раза), после добавления которых меняется победитель | H2 |
| M3 | фактическое влияние критерия качества против заявленного веса (векторная и min-max нормализация) | H1 |
| M4 | доля датасетов, где победитель режима A статистически неотличим хотя бы от одной модели | мотивация |
| M5 | средняя потеря основной метрики: победитель A против победителя C | цена компромисса |
| M6 | вердикты устойчивости режима C | описательно |
| M7 | время работы `analyse` при 5–100 альтернативах | применимость |
| S1 | синтетика: частота rank reversal от приманки в B и C при n = 4, 8, 16 (300 матриц на n) | H2 |

## 5. Критерии подтверждения и опровержения

* **H1 подтверждается**, если в большинстве сценариев без ограничений фактическое влияние
  качества при векторной нормализации меньше трети заявленного веса; опровергается,
  если влияние сопоставимо с весом.
* **H2 подтверждается**, если M2 и S1 для B больше 0, а для C равны 0. Ненулевое значение
  для C означало бы ошибку реализации (свойство доказано в MATHEMATICAL_MODEL.md, разд. 4).
* **H3 подтверждается**, если M1 для A и B больше 0. Нулевое M1 для C гарантировано
  построением и **не является** аргументом превосходства — содержательна только цена,
  измеряемая M5.
* Вывод «режим C лучше» **не делается** из того, что он выбирает другого победителя.

## 6. Угрозы валидности

* **Внешняя:** четыре малых датасета, модели scikit-learn с параметрами по умолчанию,
  одна машина. Абсолютные времена не переносимы между машинами.
* **Конструктная:** время инференса пакетное (на 1000 строк), не задержка одиночного
  запроса; размер — pickle, а не формат развёртывания (ONNX и т. п.); память не измерялась.
* **Внутренняя:** std по 5 фолдам — грубая оценка неопределённости (фолды коррелированы,
  Nadeau & Bengio, 2003); ограничения заданы на медианах той же выборки моделей.
* **Статистическая:** доли сценариев — не вероятности превосходства; сравнения
  не сопровождаются статистическими тестами значимости.

## 8. Второй эксперимент: сравнение B / C / D (гипотеза H4)

Скрипт `scripts/research/bcd_experiment.py`, результат `results/bcd_results.json`.
Те же 4 датасета, те же 80 сценариев (4 профиля × 5 наборов ограничений), seed 20261109.

**Шкалы режима D** фиксируются до сравнения: качество — естественные (ROC-AUC 0.5…1,
R² 0…1); ресурсы — логарифмические «бюджет → бюджет/100». Бюджет — граница ограничения,
если она есть, иначе «бюджет развёртывания» = 4 × медиана по датасету. Это допущение
эксперимента; шкалы замораживаются до добавления приманок и новых альтернатив.

Метрики (объявлены до запуска):

| Обозначение | Метрика | Что означает «лучше» |
|---|---|---|
| Q1 | средняя потеря основной метрики: лучшая допустимая минус у победителя | меньше |
| Q2 | доля сценариев с ограничениями, где победитель их нарушает | меньше |
| Q3 | фактическое влияние качества при профиле balanced (заявлено 50%) | ближе к 50% |
| Q4 | доля доминируемых приманок (10 на сценарий), меняющих победителя | меньше |
| Q5 | доля пар исходных альтернатив, поменявших порядок после вставки новой альтернативы из диапазона наблюдаемых значений (может быть недоминируемой; 10 на сценарий) | меньше |
| Q6 | среднее число разных победителей по 4 профилям приоритетов (1 — приоритеты не влияют) | больше, при прочих равных |
| Q7 | доля сценариев, где победитель D не меняется при множителе шкалы 10 и 1000 вместо 100 | ближе к 1 |

**Критерии.** H4 подтверждается по устойчивости, если Q4 = Q5 = 0 для D при Q4, Q5 > 0
для B; по влиянию — если Q3 для D заметно ближе к 50%, чем для B и C. Если Q1 у D хуже,
чем у C, это фиксируется как цена. Различие победителей само по себе выводом не является.

Ограничение сравнения Q1: у режима B потеря считается относительно лучшей **допустимой**
модели, хотя сам B ограничения игнорирует — его малая потеря частично объясняется тем,
что он выбирает недопустимые модели (Q2).

точный знаковый тест. Сценарный знаковый тест приводится только для справки — его
p-значения оптимистичны.
